## Keyboard shortcuts

Press `?` in the designer for the full list. The ones worth learning first:

| Shortcut | Does |
|---|---|
| `0` … `7` | Vibe chat, palette, component tree, screens, views, device and zoom, assets, settings |
| `Ctrl` + `Shift` + `E` | Switch between the designer and the block editor |
| `Shift` + `S` | Search |
| `Alt` + `C` / `Alt` + `V` | Comments / version history |
| `Shift` + `D` | Duplicate the selection |
| `Ctrl` + `0` | Fit the screen to the canvas |
