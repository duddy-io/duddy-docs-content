Assets are the files your app ships with: pictures, fonts, animations, sounds and data files. They belong to the project, every screen can use them, and they are packed into the app when you build it. Press `6`, or choose **Assets** on the left rail, to open **Media Assets**.

## Where assets live

**Media Assets** has three folders:

| Folder | Holds | Used by |
|---|---|---|
| **Drawables** | Images. | The **Image** property of an [Image](/components/content#image), and backgrounds set to **Image**. |
| **Fonts** | `.ttf` and `.otf` font files. | The font in a component's **Typography** group. |
| **Raw** | Every other file: animations, audio, video, data, and GIFs. | The **Source** of [Lottie](/components/media#lottie), [AudioPlayer](/components/media#audioplayer) and [VideoPlayer](/components/media#videoplayer), and your logic. |

Each folder has a search box, a **Grid View** and **List View** switch, **Select all**, and **Upload Media**. Select files to delete them with **Delete Media**.

Icons and shapes are not assets. The [Icon](/components/content#icon) component draws from a built-in set of 7,237 icons, and the [Shape](/components/content#shape) component draws vector shapes. The launcher icon and splash image are set in project settings, not here: see [Use an asset in a component](#use-an-asset-in-a-component).

## Upload an image, font or file

<Steps>
  <Step>In **Media Assets**, press **Upload Media**.</Step>
  <Step>On the **Local** tab, drop files onto the box, or choose **browse** to pick them from your computer. You can add several at once.</Step>
  <Step>Press **Upload media**. Each file is filed by its extension, and you land on the folder it went to.</Step>
</Steps>

The extension decides the folder, whichever folder you started from:

| Extension | Folder |
|---|---|
| `.png`, `.jpg`, `.jpeg`, `.webp`, `.bmp`, `.tiff`, `.svg`, `.ico` | **Drawables** |
| `.ttf`, `.otf` | **Fonts** |
| Anything else, such as `.gif`, `.json`, `.mp3` or `.mp4` | **Raw** |

A file from your computer must be 1 MB or smaller. Larger files are left out of the upload, with a message naming each one. Every asset ships inside the app on every phone that installs it, so small files keep your app small.

You can also upload while you design: an **Image** property's picker has **Upload New**, which opens the same dialog.

### Which image formats work in builds

| Format | Android build | iOS build |
|---|---|---|
| PNG, JPG, WebP | Included | Included |
| SVG | Left out | Included, kept as a vector |

TIFF and ICO images are also left out of Android builds. Use PNG, JPG or WebP for any picture your app needs on every platform. For vector art on Android, use an Icon or a Shape, or turn the picture into a Shape with [Trace to shape](#trace-an-image-into-a-shape).

## Find photos on Pixabay

On the **Drawables** folder, the upload dialog has a **Pixabay** tab that searches Pixabay's free photo library. Search, then press **Import** on a photo to add it to **Drawables**. The tab needs a free Pixabay API key, which you can connect from the tab itself. Pixabay's own licence covers what you may do with each picture.

## Generate an image with AI

The upload dialog's **Imagine** tab makes a new image from a description:

<Steps>
  <Step>Describe the image in the prompt box, such as "a flat illustration of a delivery scooter, cream background".</Step>
  <Step>Choose a model and a style. Models your plan does not include are shown but cannot be chosen.</Step>
  <Step>Press **Generate**, and check the preview.</Step>
  <Step>Press **Import** to save it to **Drawables**. Import it within 30 minutes, or generate it again.</Step>
</Steps>

You can also type `/imagine` and a description in the [Vibe mode](/ai/overview) chat. Generating an image spends [credits](/getting-started/credits-and-plans).

## Let Vibe mode add photos and illustrations

When Vibe mode builds screens, it searches Pixabay for the photos they need, with your Pixabay key if you have connected one, and stores each photo it finds as an asset. It makes illustrations, and photos the search could not find, with an image model only if **AI images** is turned on under **Settings → Project → Build**. It is off by default, and each image spends credits. With it off, those places show a coloured tile instead.

## Use an asset in a component

- **A picture:** select an [Image](/components/content#image), open its **Image** property, and pick the file. **Image Size** sets how it fits: **Auto**, **Center**, **Cover** or **Fill**.
- **A background:** in a **Background** picker, choose **Image** and pick the file. See [Theme colours, dark mode and styling](/guides/designing/theme).
- **An animation, sound or video:** type the file's name, such as `confetti.json`, in the **Source** of a Lottie, AudioPlayer or VideoPlayer. These also accept an https link, which suits large media.
- **A font:** choose it in **Select Font Family** from a component's **Typography** group. A font you upload draws on the canvas, but Android and iOS builds include the built-in families only, so use a built-in family for text that must keep its typeface in the installed app.
- **The launcher icon and splash image:** upload them under **Settings → Project → Assets**, as **Launcher icon** (a square PNG with no rounded corners, which Duddy masks for each platform) and **Splash image**. They accept JPG and PNG. See [Project settings](/getting-started/project-settings).

### Trace an image into a shape

On the **Drawables** folder, **Trace to shape** turns an SVG, PNG, JPG or WebP into an editable Shape component. Adjust **Detail Threshold** and **Curve Smoothing** until the outline looks right, then press **Insert Shape Component** to add it to the open screen.

## Replace or delete an asset

To replace a file, upload a new one with exactly the same name. It overwrites the old file, and every component that uses it shows the new one, without you touching any screen.

To delete files, select them and press **Delete Media**, or use the delete button on one file. Deleting is permanent. On the canvas, a component whose picture was deleted draws nothing where the picture was, so pick another file for it.

## Size and storage limits

- A file uploaded from your computer must be 1 MB or smaller.
- Each project also has a total asset storage limit set by your plan. See [Plans and limits](/account/plans-and-limits).
- For audio or video larger than these limits, host the file yourself and put its https link in the component's **Source**.

## Name files so builds keep them

Builds turn each file name into a resource name: lowercase, every character other than a letter or a digit becomes `_`, repeated underscores become one, and a name that starts with a digit or is a Java keyword, such as `new` or `class`, gets `img_` in front. `Hero Banner (final).png` becomes `hero_banner_final`.

Two files in one folder whose names turn into the same resource name clash, and the Android build leaves one of them out. `Hero Banner.png` and `hero_banner.jpg` both become `hero_banner`. Name files in lowercase with underscores from the start, such as `hero_banner.png`, and give every file a different name.

## Troubleshooting

<Accordion>
  <AccordionItem value="over-1mb" title='"hero.png" is over the 1 MB limit, so it was left out.'>
    **Why:** files uploaded from your computer must be 1 MB or smaller.

    **Fix:** export the image smaller, for example as WebP or at a lower resolution, and upload it again. For large audio or video, use an https link in the component's **Source**.
  </AccordionItem>
  <AccordionItem value="storage-limit" title="Asset storage limit reached for your plan">
    **Why:** the project's assets have reached your plan's storage total. The message ends with how much is used out of the limit.

    **Fix:** delete files you no longer use, upload smaller versions, or see [Plans and limits](/account/plans-and-limits) for a plan with more storage.
  </AccordionItem>
  <AccordionItem value="missing-on-android" title="An image shows on the canvas but not in the Android app">
    **Why:** the file is an SVG, TIFF or ICO, which Android builds leave out, or its name clashes with another file's.

    **Fix:** upload it as PNG, JPG or WebP, or rename it so no two files turn into the same name. The build log lists each skipped file.
  </AccordionItem>
  <AccordionItem value="font-missing" title="A font I uploaded does not appear in the built app">
    **Why:** builds include the built-in font families only.

    **Fix:** choose a built-in family in **Select Font Family** for that text.
  </AccordionItem>
  <AccordionItem value="image-expired" title="This image is no longer available. Generate it again to add it.">
    **Why:** a generated image waits 30 minutes for you to import it.

    **Fix:** press **Generate** again, then **Import**.
  </AccordionItem>
  <AccordionItem value="pixabay-key" title="Pixabay did not accept that key. Check it and try again.">
    **Why:** the Pixabay API key was mistyped or is not valid.

    **Fix:** copy the key again from your Pixabay account.
  </AccordionItem>
  <AccordionItem value="coloured-tiles" title="Screens from Vibe mode show coloured tiles instead of pictures">
    **Why:** **AI images** is off, so Vibe mode does not make the illustrations and photos it could not find.

    **Fix:** turn on **Generate images with AI** under **Settings → Project → Build**, or add pictures yourself.
  </AccordionItem>
</Accordion>
