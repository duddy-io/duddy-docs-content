Duddy is an app builder that runs in your browser. You design screens on a canvas,
describe behaviour with blocks that snap together, and Duddy compiles the result into
a real Android app, a real iOS app, and a web app — from one project.

There is no code to write, and nothing to install.

## How a project becomes an app

A Duddy project is a set of **screens**. Each screen holds a tree of **components** —
a Column with a TopBar, some text, an image, a button — and a **logic workspace** where
blocks describe what happens when someone uses it.

When you build, Duddy compiles that project into native source for the target you picked
and runs the platform's real toolchain over it. An Android build is compiled Java running
in a real Android app; an iOS build is Swift built with Xcode; a web build is a bundle you
can host or install as a PWA. There is no interpreter shipped in the middle, which is why
the result behaves like an app rather than a website in a wrapper.

## Three ways to build the same thing

Nothing here is a separate mode you have to commit to. All three write into the same
project, and you can move between them mid-screen.

| | What it is | Best for |
|---|---|---|
| **Canvas** | Drag components from the palette, nest them, size and style them in the properties panel. | Precise layout, and changing anything the AI produced. |
| **Blocks** | A visual logic editor. Events, conditions, requests and storage are blocks that only connect where they make sense. | Behaviour: taps, navigation, API calls, saved data. |
| **Vibe (AI)** | Describe a screen or a whole app in the chat and it gets built. | Getting past a blank canvas, and bulk edits. |

<Callout type="info">
  Anything the AI produces is ordinary project structure — the same component tree and the
  same blocks you get by hand. There is no generated layer to untangle before you can edit it.
</Callout>

## What you get

- **Android** — an `.apk` to sideload or an `.aab` to upload to Google Play.
- **iOS** <Badge type="beta" /> — an `.ipa`, built on real Xcode and signed with your own
  Apple key.
- **Web** <Badge type="beta" /> — a bundle you can download, or host on a live link straight
  from the builder.
